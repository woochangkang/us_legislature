# IRA 최종 조립 요건 후속 조사계획

작성일: 2026-10-01

새 조사는 계획 수립 상태이며 아직 실행하지 않았습니다. 기존 E01–E20은 확보된 근거이고, 아래 신규 확보 대상은 별도 확인이 필요합니다.

## 실행 순서

1. Q06 부록 정비와 문서 목록 작성
2. Q03 하원 문구 계보 확인
3. Q01 북미 확대와 Q02 시행일 변경 추적
4. Q04 인과관계 비교 및 Q05 선행안 범위 점검
5. 증거 검수 후 사이트의 연표·인물 설명·PDF 강조 갱신

## 공통 기록·판정 원칙

문서 ID, 질문 ID, 원문 URL, 기관, 제목, 문서 작성일, 공개일, 확보일, 법안 버전, 처리 상태, 파일 SHA-256, PDF 쪽수, 인쇄 쪽수, 영문 인용, 문맥, 행위자, 역할, 주장, 증거 강도, 반대 증거를 기록한다.

직접 증거 / 정황 / 미확정을 구분한다. 언론 보도는 원문 탐색의 단서로 사용하고, 단독으로 작성자를 확정하지 않는다. 검색 일자·검색식·검색 범위·결과 없음도 남긴다. 모든 예정 자료군을 점검하고 새 연결 증거가 없으면 미확정으로 종료하고 미공개 기록의 필요성을 적는다. 의원실 접촉이나 정보공개청구는 별도 후속 절차로 둔다.

## Q01 · 북미 확대의 요구자·수용자·문구 작성 경로

우선순위: 최우선 | 상태: 계획 준비·미착수 | 범위: 2021.12–2022.07

### 확보할 자료

- 상원 재무위·슈머·맨친 의원실의 당시 보도자료·서한·공개 초안

- 캐나다 외교부·재무부의 면담 설명, 의회 CIIT 증언과 서면자료

### 출발 검색식

- `"final assembly" "North America" "2022"`

- `"electric vehicle" "Freeland" "Schumer" "2022"`

### 작업 절차

1. 2021년 12월 BBB와 7월 27일 IRA를 양 끝에 두고 중간 문서의 작성일·공개일을 각각 기록한다.

2. 미국→북미 문구가 처음 관찰되는 문서를 찾고, 요구 발신자·수신자·답변·후속 초안의 시간 순서를 연결한다.

3. 날짜가 명시된 수정 지시, 작성자 발언, 미국 측 수용 기록을 우선 확인한다.

판정 기준: 동등 대우 요구만으로는 부족하다. 해당 조항을 특정한 요구와 미국 측 수용·수정 기록이 연결될 때 직접 기여로 판정한다.

산출물: 북미 확대 사건표, 중간 초안 대조표, 행위자별 증거 메모

## Q04 · 캐나다의 영향과 경쟁 설명 비교

### 출발 검색식

## Q06 · 스캔 부록의 OCR과 인용 가능한 페이지 지도

우선순위: 기반 정비 | 상태: 계획 준비·미착수 | 범위: 2021.05.26 속기록 PDF 223–332쪽

### 확보할 자료

- 이미 확보한 332쪽 속기록 원본과 수정안 모음 PDF

### 출발 검색식

- `OCR 후: "final assembly", "Stabenow", "electric", "five years", "2025", "2026"`

### 작업 절차

1. 원본 SHA-256을 보존하고 별도 작업본의 223–332쪽을 OCR한다.

2. 110쪽 전체를 수정안·서면 진술·기타로 분류하고 PDF 쪽수와 인쇄 쪽수를 연결한다.

3. 검색 적중 면과 인접 면을 원본 이미지로 대조한다. 이름·날짜·숫자·부정어는 직접 검수한다.

4. 기존 수정안과 중복 문서는 연결하되 독립된 근거로 중복 집계하지 않는다.

판정 기준: OCR 텍스트만으로 인용을 확정하지 않는다. 이미지 대조와 페이지 대응이 확인된 구절만 공개 증거에 추가한다.

산출물: 부록 OCR 텍스트, 페이지 지도, 자료 목록, 검수 기록

연결 작업: 먼저 수행하여 이후 검색 누락 감소
